# Attack Trails

An SKSE plugin that adds visual trails to weapons and arrows, inspired by Crimson Desert.

* Particle Trails: Power attacks leave glowing trails behind weapons.
* Arrow Trails: Arrows fired from a bow held fully drawn for at least 1 second (default) leave trails.
* Enchantment Colors: Customize the trail color for each enchantment.
* Weapon Selection: Apply trails to all weapons, unique weapons only, or a custom list. Each weapon can have its own trail color.
* Combat Mod Compatibility: Works with vanilla and modded combat animations. The video showcases For Honor animations as an example.
* NPCs and Normal Attacks: NPCs can leave trails, and trails can also appear during normal attacks. Both features are optional.

## Compatibility and Performance

* Precision Trails: Compatible with this mod, but disabling Precision Trails is recommended for more consistent visuals.
* Performance: You shouldn't notice a performance impact unless many NPCs are using these effects simultaneously.
* Save Safety: Safe to install and uninstall mid-playthrough.
* Load Order: Load order doesn't matter.
